# GoalFlow — Android приложение

Трекер целей и накоплений. Flutter.

## Сборка

GitHub Actions собирает APK автоматически при push в `main`.
Скачать: вкладка **Actions** → последний build → **Artifacts** → `GoalFlow-APK`.
Или **Releases** → скачать APK.

## Установка

Скачай APK на телефон → разреши установку из неизвестных источников → установи.

Требования: Android 5.0+ (API 21+).

## Возможности

- 5 валют с авто-конвертацией
- Дедлайн целей с расчётом «сколько нужно в месяц»
- Рекомендации: сколько копить в день/неделю/месяц, или за сколько накопишь
- Доходы и расходы с привязкой к целям
- Уведомления при достижении 100%
- История операций с редактированием
- Архив завершённых целей
- Экспорт JSON

## Стек

Flutter 3.19, Dart 3.0+, Provider, SharedPreferences, HTTP, flutter_local_notifications.

# GoalFlow — Android Flutter App

Трекер целей и накоплений.

## Сборка
GitHub Actions собирает APK автоматически. Скачать: Actions → Artifacts → GoalFlow-APK.

## Возможности
- 5 валют, автоконвертация
- Дедлайн, рекомендации, уведомления
- Доходы/расходы, история, архив
- Экспорт JSON

## Стек
Flutter 3.19, Provider, SharedPreferences, HTTP, flutter_local_notifications.

# Дорама Пульс

Дорамы Кореи, Японии, Китая, Таиланда и Тайваня 2020–2026 в реальном времени, названия и описания на русском.

- Данные: TVmaze + Викиданные (анонсы)
- Перевод: словарь → Викиданные/Википедия → бесплатные модели OpenRouter → встроенный переводчик
- Сборка APK: GitHub Actions (вкладка Actions → Build APK → Artifacts / Releases)
- Ключ OpenRouter: задаётся в секрете репозитория `OPENROUTER_KEY` или в Профиле приложения

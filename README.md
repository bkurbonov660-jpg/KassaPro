# Дорама Пульс v2.4 — Корея 2022+

Корейские дорамы с 2022 года и до сегодня. Названия и описания на русском.

## Источники названий
1. Кинопоиск.dev (токен в `lib/secrets.dart`)
2. Викиданные / RU-Википедия
3. ИИ OpenRouter
4. Встроенный словарь

## Установка
Скачивайте APK из Releases → Assets (arm64 для большинства телефонов).
Не качайте zip из Artifacts. Сверяйте SHA256 с SHA256SUMS.txt.
Workflow сам проверяет целостность APK (unzip -t, apksigner verify).

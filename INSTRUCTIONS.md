# Master & Client - Руководство

1. Откройте Firebase Console, создайте проект.
2. Включите Cloud Firestore (в тестовом режиме) и Authentication (Anonymous/Google).
3. Скачайте `google-services.json` и загрузите его в свой репозиторий по пути `android/app/google-services.json`.
4. Перейдите в раздел Actions на GitHub, дождитесь завершения сборки и скачайте `Master_and_Client_APK` из Artifacts.
